# Market Control

Sistema de gerenciamento de estoque para estabelecimentos comerciais, desenvolvido em Java.

## Objetivo

Controlar produtos, fornecedores, lotes e movimentações de estoque, identificando mercadorias vencidas ou próximas do vencimento para auxiliar na prevenção de perdas.

## Funcionalidades

- [ ] Cadastro de produtos
- [ ] Cadastro de categorias
- [ ] Cadastro de fornecedores
- [ ] Controle de lotes e validades
- [ ] Registro de entradas e saídas
- [ ] Controle de perdas
- [ ] Alertas de vencimento
- [ ] Relatórios de estoque
- [ ] Gerenciamento de usuários

## Tecnologias

- Java 21+
- Maven
- JUnit 5
- Java Collections Framework

## Arquitetura

Aplicação inicialmente desenvolvida em Java puro, com armazenamento em memória e separação entre domínio, serviços e persistência.

## Documentação

Consulte a pasta `docs/` para os requisitos funcionais, requisitos não funcionais, regras de negócio e modelagem das entidades.

## Status

Em desenvolvimento — Etapa 01: preparação do projeto.

## Objetivo de evolução

Futuramente, o sistema deverá possuir persistência em banco de dados, API HTTP e interfaces web ou mobile.
